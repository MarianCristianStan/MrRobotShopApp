# MrRobotShopApp

This project is based on the original **MR-Robot e-commerce application**:

https://github.com/MarianCristianStan/Mister-Robot

I used the application as a practical environment to explore and implement **DevSecOps and cloud security concepts**, including security checks, Docker containerization, CI/CD workflows, and cloud deployment using **Microsoft Azure**.

The goal of this repository is to demonstrate the security, containerization, automation, and cloud deployment work implemented around the original application.
